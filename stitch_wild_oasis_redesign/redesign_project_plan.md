# The Wild Oasis Redesign: Product Requirements

## Overview
A comprehensive redesign of 'The Wild Oasis' hotel management system. The goal is to move from a utility-focused data repository to a high-fidelity, cognitive dashboard that reduces staff fatigue and leverages modern UI trends.

## Design Direction
- **Modern Aesthetic:** Clean, minimalist, and "Bento Box" modular layouts.
- **Staff Well-being:** Native Dark Mode support for overnight shifts.
- **Untethered Management:** Tablet-first responsiveness for mobile lobby management.
- **Interaction:** Micro-interactions for status changes and pulsing visual cues for high-priority alerts.

## Core Screens
1. **Dashboard (The Living Map):**
   - High-level stats: Occupancy, daily revenue, check-ins/outs.
   - Interactive 'Bento' widgets for immediate tasks.
   - Predictive AI insights for staffing and pricing.
2. **Bookings (Lifecycle Management):**
   - Streamlined list with visual lifecycle tracking (Unconfirmed -> Checked In -> Checked Out).
   - Advanced filtering and quick-action status updates.
3. **Cabins (Resource Mapping):**
   - Visual grid of cabins with real-time status (Available, Maintenance, Occupied).
   - Quick edit for cabin details and pricing.
4. **Guests (Hospitality CRM):**
   - Guest profiles with stay history and preferences.
   - Simplified guest check-in/out flow.
5. **Settings (System Config):**
   - Hotel parameters, cabin management, and theme toggles.
